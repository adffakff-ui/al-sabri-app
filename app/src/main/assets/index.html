نبذة عن التطبيق والمنظومة القرآنية

تطبيق رسمي متكامل لإدارة حلقات تحفيظ القرآن الكريم بمجمع هائل سعيد أنعم. يوفر نظاماً متطوراً لإدارة الحلقات، المتابعة الرقمية، والمزامنة مع صلاحيات مُحددة لكل فئة داخل المنظومة.

📅 جدولة مواعيد التسميع وتنبيهات FCM

تحديد مواعيد التسميع المستهدفة للطلاب وإرسال إشعارات تلقائية فورية للطالب وولي أمره عبر Firebase Cloud Messaging.

⚡ محرك المزامنة اللحظي

🔒 نظام الصلاحيات المقيدة (RBAC)

⭐ قسم المشرف العام

📖 القراءات العشر والمذاهب الإسلامية
